## 分级（严格按这个定，宁低勿高）

- **P1**：合并后会让用户可见的功能坏掉 / 回归 / 丢配置或数据。必须写出具体触发条件 → 中间态 → 用户看到的后果；写不出完整链条的不许定 P1。
- **P2**：真实但影响面有限的功能问题，或缺测试导致回归风险明确。同样要给触发路径。
- **P3**：罕见边界、理论竞态、防御性加固、可维护性。
- **nit**：风格、命名、注释、PR 描述与实现不符。

以下一律不得高于 P3：只有"可能/理论上"而给不出触发路径的；需要用户手改配置文件或极端环境才触发的；
与本 PR 无关的既有问题（单独列到"既有问题"，不计入本 PR 级别）。
