# jason-skills

Skills I use for day-to-day project maintenance.

| Skill | What it does |
|---|---|
| [jason-review](jason-review/SKILL.md) | Evidence-first PR review for [cc-switch](https://github.com/farion1231/cc-switch): purpose, approach, a quantified necessity verdict, then a deep review with merge-tree verification. Runs an independent Codex review in parallel when the Codex CLI is installed. |

Each skill is a folder with a `SKILL.md`. Copy the folder into `.claude/skills/` of your project (or `~/.claude/skills/`) to use it with Claude Code.

Note: these skills are written for my own setup. Some paths (for example the cc-switch checkout location) are hardcoded and need adjusting before reuse.
